## Usage
Each file is self-contained: Trigger / What it does / Process / Output format / Guardrails.
Drop the relevant ones into your tool's rules/context folder, or paste into a system prompt.
Note on 35-44: these describe autonomous, multi-step, self-checking *behavior* achievable
through instructions to any capable coding agent. They don't replicate platform-specific
features like live voice/vision (e.g. Astra, Omni) — those are runtime capabilities, not
something a markdown instruction set can add.
