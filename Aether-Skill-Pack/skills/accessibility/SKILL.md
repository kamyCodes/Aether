# Accessibility
Use semantic HTML.
Ensure keyboard access and visible focus.
Maintain sufficient contrast.
Provide accessible names and labels.
Do not rely on color alone.
Respect reduced-motion preferences.
Handle focus management for dialogs, menus, navigation, and dynamic content.
Use ARIA only when native semantics are insufficient.
Validate common WCAG expectations without overengineering.
