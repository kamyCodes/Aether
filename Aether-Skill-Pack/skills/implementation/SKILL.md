# Implementation
- Follow repository patterns.
- Reuse existing utilities/components/services.
- Keep functions and modules cohesive.
- Handle errors explicitly.
- Preserve public contracts unless change is required.
- Make incremental edits and inspect results.
- Avoid speculative abstractions and premature generalization.
- Keep comments focused on non-obvious why, not obvious what.
