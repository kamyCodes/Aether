# Agent Coordination
Delegate only when specialization or parallelism provides clear value.
Give each subagent a precise objective, relevant context, constraints, and expected output.
Keep a single source of truth for decisions.
Do not have multiple agents independently rewrite the same files.
Require delegated work to return evidence, not just conclusions.
A coordinator integrates results and performs final verification.
