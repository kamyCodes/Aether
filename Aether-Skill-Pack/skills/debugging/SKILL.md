# Debugging
Use: observe → reproduce → localize → hypothesize → test hypothesis → fix → verify.
Classify failures as syntax, type, dependency, config, state, concurrency, network, API, database, rendering, performance, security, or logic.
Read complete errors and relevant surrounding code.
Do not repeatedly patch symptoms without testing a root-cause hypothesis.
