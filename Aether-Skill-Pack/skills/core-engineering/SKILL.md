# Core Engineering
- Understand before editing; inspect architecture, conventions, dependencies, and relevant tests.
- Prefer existing abstractions and the smallest correct change.
- Preserve unrelated behavior.
- Never invent files, APIs, dependencies, commands, or configuration.
- Treat external input as untrusted.
- Verify every meaningful change.
- Never claim success without evidence.
- Prefer readable, maintainable code over clever code.
- Keep scope tight and explain justified scope expansion.
