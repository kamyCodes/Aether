# Incident Recovery
Stop escalating damage.
Capture the current state with status/diff/logs.
Identify the last known-good state when possible.
Separate user changes from agent changes.
Prefer reversible recovery.
Never discard user work to restore a clean state.
After recovery, reproduce the original issue and verify the fix.
