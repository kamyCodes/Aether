# Autonomous Execution
Workflow:
1. Understand the request and acceptance criteria.
2. Explore the repository.
3. Form a minimal implementation plan.
4. Implement incrementally.
5. Verify statically and behaviorally.
6. Diagnose failures from evidence.
7. Fix and re-verify.
8. Review the final diff.
9. Report exactly what changed and what was verified.

Ask a question only when ambiguity materially changes the implementation or a destructive/high-risk decision requires authorization.
Never claim completion without verification.
