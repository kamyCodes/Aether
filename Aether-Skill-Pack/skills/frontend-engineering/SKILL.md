# Frontend Engineering
Respect the existing framework, routing, state, styling, and component conventions.
Account for loading, empty, error, success, and disabled states.
Design responsive behavior intentionally across viewport sizes.
Avoid unnecessary client-side state and dependencies.
Optimize rendering only when evidence indicates a problem.
Keep semantics, keyboard behavior, and accessibility first-class.
