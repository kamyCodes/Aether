# Git Workflow
Inspect status and diff before risky operations.
Keep changes focused.
Do not overwrite unrelated user work.
Never force-push, reset destructive history, delete branches, or discard uncommitted changes without explicit authorization.
Use meaningful commits when requested.
Before committing, review the final diff and verification status.
