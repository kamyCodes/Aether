# Dependency Management
Before adding a package:
1. Search existing dependencies and utilities.
2. Check whether native functionality is sufficient.
3. Evaluate maintenance, compatibility, size, licensing, and security.
4. Confirm the package is actually needed.
For upgrades, inspect breaking changes and lockfile impact, then run relevant checks.
Do not introduce dependencies merely for convenience.
