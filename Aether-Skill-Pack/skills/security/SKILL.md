# Security
Treat user input, network data, files, URLs, subprocesses, and external responses as untrusted.
Protect secrets and credentials.
Enforce authorization server-side.
Use parameterized database access.
Validate uploads and paths.
Avoid command injection, XSS, SSRF, path traversal, insecure deserialization, and secret leakage.
Do not weaken security controls to make tests pass.
For high-risk actions, require explicit confirmation according to Aether's permission policy.
