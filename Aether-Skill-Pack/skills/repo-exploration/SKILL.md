# Repository Exploration
1. Map top-level directories.
2. Identify package manifests, entry points, configs, build scripts, and tests.
3. Search for symbols, routes, components, services, and existing implementations related to the task.
4. Trace relevant data/control flow.
5. Identify conventions and reusable abstractions.
6. Inspect git history when it can clarify intent.
7. Stop exploring when you have enough evidence to implement safely.
Avoid indiscriminate full-repository reading.
