# UI Design
Prioritize hierarchy, clarity, rhythm, restraint, and consistency.
Use the existing design system before inventing primitives.
Maintain coherent typography, spacing, radii, elevation, icons, and interaction states.
Use motion to communicate state and hierarchy, not decoration.
Avoid excessive gradients, glass effects, cards, pills, shadows, and ornamental UI.
For every major component define normal, hover, focus, pressed, loading, empty, and error states where relevant.
